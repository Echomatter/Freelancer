# Reason through

Consider Sequential Thinking for difficult or ambiguous problems, conflicting
evidence, multiple plausible causes, intertwined dependencies or a causal chain
that needs revision. It can structure hypotheses, alternatives, assumptions and
unresolved questions; it provides exploration, not verification. Keep it
proportional and return to concrete source, browser observations or project checks
to test conclusions. Ordinary debugging/reasoning remains sufficient for routine
work. If unavailable or failing, reason normally without blocking the parent task.

This skill is optional guidance. It does not grant or gate access to Sequential Thinking or other tools.
