# Worker budget

[Overview](../README.md) · [Architecture](ARCHITECTURE.md) · [Agents](named-agents.md)

Open **Project settings → Delegation** for project defaults or a selected chat. You can work successfully without configuring a team.

| Control | Meaning |
| --- | --- |
| Agent decides / Work directly | Allow useful workers, or disable delegation. |
| Simultaneous workers | One to six active assignments across the tree; a ceiling. |
| Maximum depth | One to six nested levels, also bounded by native OpenCode. |
| Free-model preference | Prefer eligible free capacity or prioritize capability. |
| Subscription capacity | Free models only, or allow subscription capacity with native consent. |

Native paid_delegate permission governs subscription dispatch. The normal route does not ask a second model-choice question. Separately metered delegation is unavailable; parent model choice stays unchanged. Advanced model/provider exclusions, context limits and timeouts remain useful. Agent/workflow names do not narrow the pool.

Saving is revision-checked and errors preserve your form. Future roots capture new limits; current restrictions may tighten existing dispatches but never expand their authority. Saving does not cancel active work.

No eligible route returns unavailable; concurrency refusal is a scheduling conflict. Sequence or narrow work rather than weakening permissions. Repeated failures require diagnosis; inspect partial output and uncertain stops before overlapping work resumes. Review can request diversity without a mandatory pipeline. Git uses the project agreement from any capable agent/workflow.
