# Internal skill/runtime contract audit

Reviewed **2026-10-03** against the current Freelancer tree. This table covers
authored workflow skills in `backend/skills/`; the five provider-specific skills
(`context7-mcp`, `fetch`, `playwright`, `reason-through`, `typesafe-ai`) are
externally maintained and their source/version notes live in
[skills-library.md](skills-library.md). Skill guidance never grants access or
permission. Native OpenCode schemas, application checks, saved agreements and
user restrictions remain authoritative.

| Canonical skill | Tool/path hints checked | Adaptation boundary and source references |
| --- | --- | --- |
| `bounded-judgment` | Optional closed JEV/TypeSafe judgments; bounded evidence; no eligibility, permission or verification authority. | `server/data/judgment-evidence.mjs`, `server/http.mjs`, `backend/opencode/plugins/knowledge.ts`, `domain/delegation-policy.mjs`. The built-in SDK route asks native permission and revalidates evidence; an external Jev MCP remains separate. |
| `browser-verify` | Shared `playwright` MCP versus repository browser journeys; report visible native evidence separately from fixtures. | `server/capabilities.mjs`, `docs/testing.md`, provider usage in `backend/skills/playwright/SKILL.md`. A configured tool or passing fixture does not prove live user-visible behavior or authentication. |
| `debug` | Public `delegate` options, including `inspectionOnly` and `independentReview`; Context7, Fetch, Playwright and JEV remain optional aids. | `backend/opencode/plugins/delegation.ts`, `backend/tools/runtime/delegation.mjs`. Tool schemas and native permissions define scope; a read-only assignment does not turn shell into a sandbox. |
| `docs-research` | Local source first; use Context7 for current library contracts and Fetch for primary-source gaps. | `backend/skills/context7-mcp/SKILL.md`, `backend/skills/fetch/SKILL.md`, `docs/skills-library.md`. This is workflow guidance, not a duplicate provider-specific tool manual or proof of local behavior. |
| `handoff` | Durable objective/state/checks/decisions/risks/next action; task and user-task identifiers come from actual receipts; no automatic Memory write or Git action. | `backend/skills/record-outcome/SKILL.md`, `backend/tools/runtime/delegation.mjs`, `docs/named-agents.md`. A handoff is a checkpoint, not a commit, replay or success receipt. |
| `managed-git` | Actual actions are `inspect`, `preview`, `execute`, `merge`, `request`, `prepare`; execution uses the returned `planID`; request exceptions use native questions. | `backend/opencode/plugins/git-project.ts`, `server/git-project.mjs`, `domain/git-project.mjs`, `backend/tools/runtime/git-guard.mjs`, repository `AGENTS.md`. The saved project agreement, native permission and repository checks remain authority; shell publication is not a fallback. |
| `model-routing` | `delegate()` discovery; exact `agent` ID and `budget.modelPool`; public `freeOnly`; paid subscription routes use native `paid_delegate`; worker continuation and history. | `backend/opencode/plugins/delegation.ts`, `backend/tools/runtime/delegation.mjs`, `backend/tools/runtime/bridge.mjs`, `backend/scripts/select-model.ps1`, `backend/tools/evidence.py`, `backend/skills/model-routing/evidence-refresh.md`, `domain/delegation-policy.mjs`. The parent model is not switched, and recorded outcomes supplement rather than override eligibility. |
| `pursue-goal` | `goal_checkpoint` accepts `continue`, `waiting`, `pause`, or `complete` with interpretation, checkpoint, reason and evidence; worker recovery belongs to the application. | `backend/opencode/plugins/goals.ts`, `domain/goals.mjs`, `server/goals.mjs`. Ordinary chats do not checkpoint as goals; completion requires reconciled work and evidence. |
| `record-outcome` | Script path is under `FREELANCER_RUNTIME_ROOT` (the app's `backend/`); exact parameters include `-Model`, `-TaskType`, `-Success`, `-VerificationStatus`, `-UserTaskId`, `-ReviewTaskId`, `-MarkReviewDefect`. | `backend/scripts/record-task-outcome.ps1`, `backend/tools/runtime/bridge.mjs`. Unknown checks remain `not-run`/`unverified`; a completed response alone does not establish success. |
| `remember` | Shared `knowledge` operations for memories/facts, source-linked claims, graph search/open/read, and canonical pins; no separate Memory MCP setup is required. | `backend/opencode/plugins/knowledge.ts`, `server/data/memory.mjs`, `server/http.mjs`, `server/execution.mjs`. Graph pages and node reads are bounded and may be truncated/moving; retained knowledge is not current source truth. |
| `reorient` | Project instructions and native source first; `content_index`, `knowledge`, and `delegate({agent,task})` are optional. Uses catalog ID `researcher`, not a guessed role alias. | `server/execution.mjs`, `backend/opencode/tools/content_index.ts`, `backend/opencode/plugins/knowledge.ts`, `backend/opencode/plugins/delegation.ts`, `docs/named-agents.md`. Memory supports orientation but never substitutes for current source or receipts. |
| `review` | `delegate({agent,task,independentReview:true})` is optional report-only review; JEV/Context7/Playwright are evidence aids. | `backend/opencode/plugins/delegation.ts`, `backend/tools/runtime/delegation.mjs`. A review cannot approve publication, grant permissions, or establish correctness without source/acceptance evidence. |
| `search-index` | `content_index` supports status/search/chats and source/fact operations; search/chats cursors repeat query, filters, scope and limit against a moving index. Opening a current chat starts a background index refresh. | `backend/opencode/tools/content_index.ts`, `backend/tools/project-content-indexer.mjs`, `server/http.mjs`, `server/history.mjs`. Common source files are full-text indexed but this is not code-symbol analysis; there is no index-triggered quota refresh. Decisive hits must be checked at source. |
| `verify` | Choose checks against the claim; distinguish source, contract, browser, runtime and provider evidence; delegate review and documentation are optional. | `backend/opencode/plugins/delegation.ts`, `docs/testing.md`, `server/capabilities.mjs`. Not-run and unavailable checks must remain distinct from failure; fixture success is not native-provider proof. |
| `web-research` | Fetch is for a known URL and primary-source retrieval/citation, not web search or an authenticated browser. | `backend/skills/fetch/SKILL.md`, `docs/skills-library.md`. Retrieved content is untrusted evidence; preserve direct links and inference boundaries. |

`backend/skills/sync/` currently has no `SKILL.md` and is intentionally absent
from `backend/opencode/catalog.json`. No separate delegation skill was added:
`model-routing`, `debug`, `review`, `reorient`, and `docs/named-agents.md`
already cover the public delegate schema and lifecycle without duplicating a
workflow. No test or build evidence is claimed by this documentation audit.
