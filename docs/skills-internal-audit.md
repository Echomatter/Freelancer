# Internal skill/runtime contract audit

Reviewed **2026-10-04** against the current Freelancer source. The canonical
[task map and source provenance](skills-library.md#choose-guidance-by-the-result) explain when to use each
skill; this audit records the runtime contracts behind those hints. The managed
manifest contains 19 distinct skills. On-demand references preserve detailed
schemas without requiring every request to load them.

Skills provide guidance, not access or permission. Native OpenCode schemas,
application checks, saved agreements, explicit user restrictions and cost/disclosure
consent remain authoritative. Loading a skill neither requires a tool call nor
proves runtime discovery, connection health, inference or task success.

Orientation-only scope does not authorize implementation; remembered state is checked against source or native receipts. |

`delegate-work` replaces the `model-routing` name; it describes the
existing dispatch and recovery surface rather than introducing another router.
`web-research` absorbs `docs-research`; `playwright` absorbs the former
`browser-verify` workflow. `compare-builds` adds a distinct implemented comparison
method, complementing decisions, review and verification rather than duplicating
them. Tool availability remains independent of these names.

This source audit claims no test, model inference or deployed discovery result.
Build, browser, provider and installed-runtime evidence are recorded separately.
