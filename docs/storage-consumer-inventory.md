# Freelancer storage consumer inventory

**Observed:** source on `codex/storage-maintenance`, October 2, 2026. This is a source-level inventory of runtime and application-owned persistence paths; it does not inspect a user's private runtime or enumerate every external process. Normal source startup checks existing data-root contents and any existing database registration read-only before opening SQLite for writes. It initializes an empty registered `workspace-v2` database, validates that registration on later starts, and refuses non-empty unregistered state. It does not scan prior Freelancer data. Older records/JSON readers and importers below are legacy compatibility and explicit maintenance paths, not clean-start authorities. “Startup” means when the source path is reached, not that every branch necessarily runs.

## Startup and write-order dependencies

1. `server/main.mjs` resolves the fresh runtime root and acquires the OS application lock. It initializes or validates the runtime database and only then exports the runtime/data roots before OpenCode is launched. Clean bootstrap does not read a legacy data store.
2. The unified data store and app settings are constructed against this registered runtime, then OpenCode starts with inherited native configuration plus the Freelancer plugin overlay. `startServer` awaits sender, goal and schedule recovery before it binds the UI API. Git recovery also runs before serving.
3. Once bound, `server/main.mjs` saves the port and launch rendezvous and prints readiness. Native OpenCode plugins use the rendezvous to call guarded local APIs. Shutdown stops schedules/sender and host services, removes launch state, and releases the OS lock.
4. PowerShell selector/quota/outcome jobs run independently in spawned processes and use the Node state CLI with the same data root/runtime ID. Before the server starts, the CLI recognizes only paths rooted at this checkout's `backend/.state`, initializes/validates the fresh runtime, and then serves launcher/stop operations without creating `.state/webpage/records.sqlite`. The standalone Node content indexer uses the same resolver and bootstrap when `--db` is omitted. Launch rendezvous and process locks remain filesystem coordination.

## Cutover classification

- **Move as canonical Freelancer data:** records, settings domain/project agreements, goals, Git-operation receipts, sender outbox, schedules, project/session preferences, delegation receipts/decisions/bindings, model-input ID evidence, task outcomes, quota observations, pins/memories/content/OpenCode snapshots.
- **Keep as a separate settings authority:** appearance/layout and other global defaults, listen port, remote access configuration, with revision-linked backup and recovery.
- **Keep as native/source authority:** OpenCode execution/auth, Tailscale credentials/routes, project source/Git state, authored routing assets and skills.
- **Keep as process/artifact state:** OS locks, owner PID files, launch rendezvous (unless replaced with startup-safe IPC), extraction temp files, rebuildable launcher assets and temporary measurement files (or explicitly import with an expiry policy).
- **Remaining verification:** account for every runtime consumer and external helper, check all reads/writes and directory scans with a disposable unified runtime, and verify backup/restore with pending/uncertain deliveries present. Keep new-install bootstrap empty; selected restoration/import remains a separate explicit operation. Do not silently fall back to legacy storage.

## Scope and evidence limits

This inventory covers application source paths found in `server/`, `backend/tools/runtime/`, `backend/opencode/plugins/`, `backend/scripts/`, and launcher scripts under `scripts/`. The PowerShell process locks, product test harnesses and synthetic benchmark files are not production authorities. Installer copies, a running user's alternative roots, external scheduled tasks and private state contents need per-installation inventory during a real migration window. The list is a source review, not a proof that all outside writers are quiesced.
